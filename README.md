# Ritual

A web application for managing and tracking daily rituals and habits.

## 🚀 Getting Started

```bash
git clone https://github.com/eswarsamanthula/Ritual.git
cd Ritual
# Open index.html in your browser or serve with a local server
```

## 🛠️ Built With
- Vanilla JavaScript
- HTML / CSS
- Supabase (backend)
- Service Worker (PWA support)
